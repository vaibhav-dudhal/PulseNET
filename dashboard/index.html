Lamport Logical Clock Monitor

Per-node logical counters advance on local events and merge message timestamps using max(local, received) + 1.

CAUSAL ORDER
Lamport ruleLocal/send event: C = C + 1Receive message timestamp T: C = max(C, T) + 1
Start the cluster to observe logical clocks.

Logical timestamps are not wall-clock time. They preserve causal ordering when messages are received; independent concurrent events may not have a causal order.

Vector Clock Monitor

Each vector records what a node knows about events at every node. Values merge component-by-component when messages arrive.

CAUSALITY + CONCURRENCY
Vector clock rulesLocal/send event: increment this node's componentReceive: V = max(V, message.V), then increment receiver's component
Start the cluster to observe vector clocks.

A happens-before B when every component of V(A) is ≤ V(B), and at least one is smaller. Incomparable vectors indicate concurrent events.
